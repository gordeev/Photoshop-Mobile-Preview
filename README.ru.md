# Photoshop Mobile Preview

[English](README.md) · [Скачать релиз](https://github.com/gordeev/Photoshop-Mobile-Preview/releases/latest)

Предпросмотр холста Photoshop на телефоне по аналогии с Adobe Preview CC.
После редактирования, отмены или переключения документа плагин отправляет JPEG холста в sRGB, а не скриншот рабочего стола.
Можно примерить вырезы камер, скругления углов и общую опасную зону при подготовке изображений и интерфейсов для телефонов.

## Что внутри

| Папка | Назначение |
| --- | --- |
| `plugin/` | UXP-панель Photoshop: отправляет кадры в Android или браузерный сервер |
| `android/` | PS Preview: полноэкранный просмотрщик с зумом и примеркой вырезов |
| `android-overlay/` | PS Overlay: вырезы, опасная зона и картинка поверх других приложений |
| `server/` | Python-сервер для iPhone и других браузеров; общие профили вырезов |

Язык плагина зависит от языка интерфейса Photoshop, приложений — от языка Android, браузерного просмотрщика — от языка браузера. Для `ru` используется русский, для остальных языков — английский.

## Установка

### Плагин Photoshop

Нужен **Photoshop 24.4 или новее** на macOS или Windows с доступным Imaging API.

1. Скачать `MobilePreview-1.0.0.ccx` из [релиза](https://github.com/gordeev/Photoshop-Mobile-Preview/releases/latest).
2. Открыть двойным щелчком и установить через Creative Cloud Desktop. Подтвердить установку плагина не из Marketplace.
3. В Photoshop открыть **Плагины → Mobile Preview**.

Для загрузки исходников установить **UXP Developer Tools** через Creative Cloud, включить Developer Mode в настройках плагинов Photoshop и в UXP Developer Tools, затем перезапустить Photoshop. В UXP Developer Tools нажать **Add Plugin**, выбрать `plugin/manifest.json`, нажать **Load**.

### Android-просмотрщик

Нужен **Android 7.0+**.

1. Скачать и открыть `PSPreview.apk` из релиза. Разрешить установку из браузера/файлового менеджера по запросу Android.
2. Запустить **PS Preview**. На экране появятся адреса телефона, например `192.168.1.25:8765`.
3. Подключить компьютер и телефон к одной Wi-Fi сети. Вписать этот адрес в панели Photoshop и нажать **Старт**.
4. Редактировать документ. Кнопка **Отправить** передаёт один кадр без запуска постоянного обновления.

Просмотрщик должен оставаться открытым. Пока он на экране, телефон не засыпает.
Можно использовать общий VPN, например Tailscale или ZeroTier, если устройства доступны друг другу; выбрать показанный адрес этой сети.

### iPhone / браузер

На компьютере с Photoshop нужен **Python 3**. Дополнительные пакеты не требуются.

1. Скачать `MobilePreview-server-1.0.0.zip` из релиза и распаковать либо использовать папку `server/` из репозитория.
2. На macOS запустить `server/Start server.command`, на Windows — `server/Start server.bat`. Или выполнить:
   ```sh
   python3 server/preview_server.py
   ```
   На Windows вместо `python3` может потребоваться `python` или `py`. При установке Python включить **Add Python to PATH**.
3. На телефоне в той же сети открыть напечатанный адрес `http://<адрес-компьютера>:8765`.
4. В панели Photoshop оставить **`localhost:8765`** и нажать **Старт**.

На iPhone команда Safari **Поделиться → На экран Домой** открывает просмотрщик во весь экран. В обычной вкладке вырезы привязаны к окну браузера.
Для другого порта задать переменную окружения `PORT` и указать этот же порт в плагине.

Для одновременной отправки в Android и браузер указать адреса через запятую: `localhost:8765, 192.168.1.25:8765`.

### Дополнительно: PS Overlay

Нужен **Android 8.0+**. Работает независимо от Photoshop и просмотрщика.

1. Установить `PSOverlay.apk` из релиза, открыть **PS Overlay**.
2. Нажать **Разрешить показ поверх других приложений**, выдать разрешение в Android и вернуться.
3. Разрешить уведомления по запросу и нажать **Включить оверлей**.
4. Выбрать вырез, опасную зону, углы. По желанию выбрать PNG/картинку, настроить непрозрачность и режим **Растянуть** или **Вписать**.

Нажатия проходят в приложение под оверлеем. Из постоянного уведомления можно переключать вырезы и выключить оверлей. Обычный скриншот включает оверлей. На Android 12+ непрозрачность ограничена для прохождения нажатий; некоторые системные экраны скрывают оверлеи.

## Управление просмотрщиком

| Жест / кнопка | Действие |
| --- | --- |
| Тап в центре | Показать / спрятать меню; оно также исчезает через 10 секунд |
| Тап у левого / правого края | Предыдущий / следующий вырез |
| Громкость на Android | Переключение вырезов |
| Двойной тап | Вписать ↔ 1:1 по пикселям |
| Щипок на Android | Зум; перетаскивание — сдвиг |
| По ширине / По высоте | Вписать по выбранному измерению |
| Опасная зона | Красное объединение областей, закрываемых вырезами и включёнными углами |

Всего 20 профилей, включая вариант без выреза. Размер вырезов зависит от ширины экрана, ориентация — от поворота устройства. Знак `≈` обозначает приближённую форму. Это помощь при дизайне, а не сертификация под устройства; физическая камера телефона останется видна. Зум сохраняется между кадрами одинакового размера.

## Если не работает и приватность сети

- Проверить адрес, оставить приложение/сервер открытым, разрешить серверу входящие подключения в брандмауэре для частной сети. Гостевая Wi-Fi сеть может запрещать обмен между устройствами.
- Кадры передаются по **HTTP/WebSocket без шифрования и авторизации**. Использовать доверенную частную сеть или приватный VPN. Не открывать порт 8765 в Интернет. Доступный другим участникам сети сервер позволяет прочитать или подменить текущий кадр.
- Кадры хранятся в памяти. Облачного сервиса и аккаунтов нет. Плагин локально сохраняет адреса и размер картинки; Android — настройки просмотра и URI выбранной картинки оверлея.
- Начать с 1600 px. Для деталей выбрать 2400–4000 px ценой скорости обновления. Цвет переводится в sRGB; это не замена цветопробе на откалиброванном экране.
- Релизные APK подписаны отдельным ключом. Если уже установлен старый отладочный APK с другой подписью, сначала удалить его; сохранённые настройки при этом будут потеряны.

## Сборка из исходников

Нужны Bash, JDK 17+, Android SDK с **platform android-34**, Build Tools 35+ (`aapt2`, `d8`, `zipalign`, `apksigner`) и `zip`. Gradle и сторонние Java-зависимости не нужны. На Windows использовать Linux/WSL с соответствующими SDK-инструментами.

```sh
export JAVA_HOME=/путь/к/jdk
export ANDROID_HOME=/путь/к/android-sdk
bash android/build.sh
bash android-overlay/build.sh
```

Скрипты создают `PSPreview.apk` и `PSOverlay.apk` в корне репозитория. Без переменных подписи используется исключённый из Git отладочный ключ со стандартным паролем Android. **Не распространять отладочные сборки как релизные обновления.**

Для релиза указать существующий keystore с alias `pspreview` и приватный файл с паролем в первой строке; пароль ключа должен совпадать с паролем хранилища:

```sh
export KEYSTORE=/абсолютный/путь/вне/репозитория/release.keystore
export SIGNING_PASSWORD_FILE=/абсолютный/путь/вне/репозитория/release-password.txt
bash android/build.sh
bash android-overlay/build.sh
```

Хранить оба файла вне репозитория, ограничить права доступа и сделать отдельную защищённую резервную копию. Для обновлений Android нужен тот же ключ. Ключи и пароли не прикладываются к релизу.

Упаковка плагина: **UXP Developer Tools → Mobile Preview → ⋯ → Package**. Для переносимого архива исходников упаковать только содержимое `plugin/`, чтобы `manifest.json` находился в корне ZIP. Такой ZIP также приложен к релизу для загрузки через Developer Mode.

Проверки: Python и Node.js без сторонних тестовых пакетов.

```sh
python3 -m unittest discover -s tests
node tests/plugin.test.js
```

Независимый проект, не продукт Adobe.
